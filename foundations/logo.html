Logo

My personal mark, used as the signature across every page of the system.

Versions

The S.Fernandes identity is a serif S in a solid square, plus a high-contrast wordmark. The full kit is on my logo page.

Primary lockup · navigation, headers

Reversed lockup · dark sections

Wordmark · footer, documents

S mark · favicon, avatar

Usage rules

RuleValue
Clear spaceHalf the height of the S mark on every side
Minimum sizeWordmark 120px wide · S mark 16px
ColorsInk on Paper, Paper on Ink, or Brass for special use only
In this systemLockup in the navbar (24px tall) · wordmark in the footer (18px tall)
Don’tStretch, rotate, recolor or add effects

Accessibility

  • The navbar logo is a link, so its alt text says where it goes: “S.Fernandes design system home.”
  • When the logo sits next to the same text, it uses alt="" so screen readers don’t read the name twice.
  • Logos are SVG files, so they stay sharp when people zoom.
