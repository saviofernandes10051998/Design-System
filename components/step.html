Components · 04

Process step

A numbered timeline that shows how the work happened, step by step.

Example

  1. Audit

    Reviewed the live site page by page.

  2. Analyze

    Studied visitor data in Google Analytics.

  3. Present

    Shared findings in plain language.

  4. Propose

    Designed a faster way to find reflections.

.sf-steps { list-style: none; display: grid; gap: 24px; counter-reset: sfstep; }

.sf-step::before {                       /* 01, 02, 03 … */

HTML

<ol class="sf-steps">
  <li class="sf-step">
    <h3 class="sf-step__title">Audit</h3>
    <p class="sf-step__text">Reviewed the live site page by page.</p>
  </li>
  <!-- repeat .sf-step -->
</ol>

Accessibility guidelines

  • Steps use an ordered list (<ol>), so screen readers announce “list, 4 items” and the order.
  • The big numbers are added by CSS for decoration. The order comes from the list itself.
  • Each step has a real heading, so the process can be scanned with a screen reader’s heading list.
