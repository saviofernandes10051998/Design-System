Usage

  • Use one Primary button per section for the main action.
  • Use Secondary for the second choice next to a Primary.
  • Button labels are verbs that say what happens: “Read the case study,” not “Click here.”

Accessibility guidelines

  • Every button is at least 44 × 44px, so it is easy to tap.
  • Use <a> when it goes to a page and <button> when it does an action on the page.
  • A visible 3px Brass 700 focus ring shows keyboard users where they are.
  • Text contrast is 17.1:1 (Primary) and 5.4:1 (Accent). Both pass WCAG AA.
  • Disabled buttons use the real disabled attribute so screen readers announce them.
