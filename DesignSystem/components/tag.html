Pillar tag

Small labels for the seven VIA pillars. They also work as filter toggles.

Usage

The seven VIA pillars are Awareness, Dialogue, Solidarity, Spirituality, Justice & Collective Liberation, Intentional Community, and Vincentian Heritage & Living Legacy. Use static tags to label a card and button tags to filter a list.

Accessibility guidelines

  • Filter tags are real <button> elements with aria-pressed, so screen readers say “pressed” or “not pressed.”
  • The selected state adds a check mark, so it doesn’t rely on color alone.
  • A group of filter tags is wrapped in role="group" with a visible label.
  • Static tags are a list (<ul>) so screen readers announce how many there are.
